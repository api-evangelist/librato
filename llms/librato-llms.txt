# Librato

> RETIRED. Librato was a hosted metrics, monitoring and analytics service for operational data — time-series measurements, tagged metrics, dashboards ("spaces"), charts, annotations, alerts and notification services — with a JSON REST API at https://metrics-api.librato.com/v1. The San Francisco company was acquired by SolarWinds (reported at $40 million) and its platform was folded into SolarWinds AppOptics, which has itself since reached end of life. Every librato.com host now 301-redirects to the AppOptics end-of-life notice, metrics-api.librato.com no longer resolves in DNS, and the github.com/librato organization was archived on 2024-01-02. Nothing here is callable; this is a historical record. The successor product is SolarWinds Observability SaaS.

## Status

- [AppOptics end-of-life notice](https://documentation.solarwinds.com/en/success_center/observability/content/migrate-ao/ao-eol.htm): the live redirect target for every librato.com host. "As the platform has reached the end of its lifecycle, AppOptics is no longer accessible or under active development."
- [SolarWinds Observability SaaS](https://www.solarwinds.com/solarwinds-observability): the successor product.

## API

- [Librato Metrics API reference (archived source)](https://github.com/librato/api-docs): the Slate source for the former https://www.librato.com/docs/api site. Read-only since 2023-12-11 and the only surviving authoritative reference.
- Base URL: `https://metrics-api.librato.com/v1` (NXDOMAIN as of 2026-07-19)
- Resources: measurements, metrics, metric attributes, spaces, charts, chart tokens, annotations, alerts, notification services, api_tokens, snapshots, jobs; legacy dashboards and instruments.
- No OpenAPI, AsyncAPI, GraphQL or gRPC definition was ever published, so this repo carries no machine-readable spec.

## Conventions

- [Authentication](https://github.com/librato/api-docs/blob/master/source/includes/_authentication.md): HTTP Basic on every request over HTTPS — account email address as user, API token as password. No OAuth, no scopes.
- [Pagination](https://github.com/librato/api-docs/blob/master/source/includes/_pagination.md): offset/length/orderby/sort, applied consistently to every list operation, with a top-level `query` envelope carrying `length`, `offset`, `total` and `found`.
- [Response codes and errors](https://github.com/librato/api-docs/blob/master/source/includes/_response-errors.md): proprietary JSON envelope keyed on `errors`, split into `params`, `request` and `system` categories. No RFC 9457.
- No idempotency-key contract; duplicate creates return 422 Entity Already Exists.
- Rate limits were signalled through response headers; 429 Rate Limited, and 403 when an account was rate limited.
- [Quick start](https://github.com/librato/api-docs/blob/master/source/includes/_introduction.md): submit and retrieve measurements with cURL, Ruby and Python examples.

## Notes for agents

- Do not attempt to call this API. The host does not resolve and no credentials can be issued.
- If a user is looking for the live equivalent, direct them to SolarWinds Observability SaaS.
- Related SolarWinds-acquired monitoring providers in this network: pingdom, papertrail, loggly, solarwinds.
